# 评测数据管理平台（Evaluation Data Management Platform）

将「Excel 手工搬运 + 手敲公式 + 手写报告」的模型评测流程，升级为一站式网页平台：**一处管理、自动算指标、多模型对比、一键出报告**。

## 功能模块

- **题库管理**：上传题库 Excel 自动解析入库，按 `sample_id + session + round` 建立唯一键，沉淀可复用资产
- **模型数据挂载**：上传标注结果 Excel，智能列映射，按唯一键自动挂载到题库，一套题库可持续挂载 N 个模型
- **在线质检**：逐条打分、改标签、写备注，音频播放，质检进度看板
- **指标计算**：平均分、可用率、满分率、劝退率、标签数量与占比自动计算
- **多模型对比**：任意勾选 N 个模型并排对比，相对基线自动计算 DIFF（涨绿跌红）
- **标签管理**：三级标签体系（维度 > 标签 > 说明），支持停用保留历史口径
- **报告生成**：一键生成结构化报告初稿，在线编辑结论后导出 Word

## 技术栈

- React 18 + Vite
- Ant Design 5
- ECharts
- React Router

## 本地运行

```bash
cd web
npm install
npm run dev
```

访问 http://127.0.0.1:5173/

> 当前为前端原型，内置演示数据（`web/src/mock/data.js`），无需后端即可体验。
